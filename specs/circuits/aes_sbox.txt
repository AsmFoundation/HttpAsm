# aes_sbox.txt - the AES S-box (FIPS 197 5.1.1) as a straight-line program of 115 gates over
# GF(2): 79 xor, 4 xnor, 32 and. The circuit is Boyar and Peralta's, from "A new
# combinational logic minimization technique with applications to cryptology" (IACR ePrint
# 2009/191), as transcribed in BearSSL's src/symcipher/aes_ct.c (Thomas Pornin, MIT licence).
# specs/circuits.cs proves it on all 256 inputs against the S-box computed from FIPS 197's
# definition (the inverse in GF(2^8) mod x^8 + x^4 + x^3 + x + 1, then the affine map with 0x63)
# before it writes any code from it.
#
# One gate a line: "v = in i" (v is bit i of the octet), "v = a xor b", "v = a xnor b"
# (not of the xor), "v = a and b", "out i = v" (bit i of the S-box value). Every name is
# assigned once. The circuit's own names number bits from the top: x0 is bit 7.
